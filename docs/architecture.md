# 结构与算法约定

## 数学定义

默认使用 `N=8192`、`q=2013265921`、原根 `g=31`。要求 `N` 是 2 的幂、`q` 为素数且 `2N` 整除 `q−1`。令：

```
psi   = g^((q-1)/(2N)) mod q
omega = psi^2 mod q
```

循环变换采用自然序输入和输出：

```
F[k] = sum(a[j] * omega^(j*k), j=0..N-1) mod q
a[j] = N^(-1) * sum(F[k] * omega^(-j*k), k=0..N-1) mod q
```

负循环变换在正变换前乘 `psi^j`，在逆变换后乘 `psi^(-j)`。因此两组负循环变换结果逐点相乘，再进行负循环逆变换，得到 `Z_q[x]/(x^N+1)` 中的乘积。所有接口值和期望结果均采用 `[0,q)` 的标准表示；不暴露 Montgomery 域。

## 数据路径

```
主机自然序写入 ── 位反转地址 ── 系数存储
                                  │
                  正变换可选 psi^j 预处理
                                  │
              radix-2 DIT 各级蝶形 CT(a,b,w)
                         │                 │
                    因子 ROM          在线 TFG
                                  │
                  逆变换归一化 / 可选反扭转
                                  │
                           自然序读取结果
```

核心按级执行 `log2(N)` 级 radix-2 DIT。第 `s` 级的组长度为 `m=2^(s+1)`，组内第 `j` 个蝶形使用 `omega^(j*N/m)`；逆变换使用逆根。每一级均执行 `N/2` 个蝶形。

CT 蝶形为：

```
t  = b * w mod q
y0 = (a + t) mod q
y1 = (a - t) mod q
```

一套蝶形数据路径由控制器复用。该结构便于定位地址、算术和因子错误，吞吐率受串行调度限制；后续可在已验证基础上增加并行蝶形、存储分组与流水调度。

## 模乘

`mod_mul.sv` 使用常量倒数的 Barrett 约减。对 `x=a*b`，预先计算 `mu=floor(2^(2W)/q)`，再估算商并对余数作条件修正。输入必须满足 `0 <= a,b < q`；中间乘积和减法保留必要的扩展位。数据路径不进行运行时除法。

乘法器采用三寄存级流水：边沿 `k` 采样的请求，在边沿 `k+2` 后输出结果；可以每拍接收一个请求。蝶形将输入 `a` 延迟相同时间，确保与模乘结果配对。低有效复位是同步复位，应保持到至少一个时钟上升沿；复位清空流水有效位并丢弃尚未完成的事务。

Barrett 的常量宽乘法可能消耗较多 DSP 或逻辑。可综合不等于已达到某个时钟目标；需要在实际器件上检查综合结果及布局布线时序。

## 因子 ROM 与在线 TFG

ROM 模式分别为正、逆方向存储 `N/2` 个不同的根幂；同一幂表通过地址步长在各级、各组中复用。它没有为每一个蝶形重复存储相同因子。

TFG 模式为各级准备步长常量，每级从 1 开始，按 `w_next=w*step mod q` 在线递推。控制器将组内索引 `j` 放在外层、组地址放在内层，因此同一因子可连续用于所有组，随后才推进因子。递推与最后一个使用当前因子的蝶形重叠；控制器只在新因子有效时发起依赖它的蝶形。正变换预扭转和逆变换反扭转在两种模式中均使用递推生成。

该调度可能将 TFG 的乘法延迟隐藏在蝶形计算期间，ROM/TFG 核内周期可以相等。它没有预设必须出现截图所述的 5.75% 周期差；以相同边界的实际计数为准。

存储对比应分别报告：

- ROM 幂表的逻辑位数；
- TFG 级常量和状态寄存器的逻辑位数；
- 因子生成新增乘法器与控制开销；
- 实际综合得到的 LUT/FF/DSP/BRAM。

逻辑位数下降比例不能直接转换为片上 BRAM 下降比例；块 RAM 的粒度、推断结果和常量优化会改变器件资源占用。

## 主机接口

| 信号 | 用法 |
| --- | --- |
| `clk`, `rst_n` | 时钟、低有效同步复位 |
| `wr_en`, `wr_addr`, `wr_data` | 空闲时按自然序索引加载标准系数 |
| `start` | 完成加载后发起一次变换；不与写操作同拍 |
| `inverse` | 随 `start` 锁存，选择逆变换 |
| `negacyclic` | 随 `start` 锁存，选择负循环扭转约定 |
| `busy` | 核正在计算；此时不接受主机修改输入 |
| `done` | 本次运算完成时保持一个时钟周期的脉冲 |
| `rd_addr`, `rd_data` | 运算完成后按自然序读取结果 |
| `cycle_count` | 接受 `start` 时清零，每个 `busy` 周期累加，包含最后 `FINISH` 周期；加载和主机读取不计入 |

多项式乘法由测试平台依次调用核心与逐点模乘器完成；主机接口本身是一个变换核心接口。存储采用便于仿真的数组描述，异步读取可能影响 RAM 推断。若需要稳定映射 BRAM，应将接口改为同步 RAM，并相应调整控制器和验证。
