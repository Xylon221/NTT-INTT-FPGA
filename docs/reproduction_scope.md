# 复刻范围与证据边界

本工程根据用户提供的项目经历截图，从零构建功能复刻。没有原始 RTL、测试平台、约束、器件信息或综合报告，因此不表示与原项目采用相同微架构，也不能直接复现其资源和性能数字。

## 对应关系

| 截图描述 | 本工程的实现与验证方法 |
| --- | --- |
| 模乘、蝶形单元验证 | 独立 RTL 模块和自检查测试平台；模乘包括边界值与连续输入 |
| TFG 序列验证 | 在线递推 `w_next = w × step mod q`，检查产生的因子序列和停顿行为 |
| 8192 点 NTT/INTT 全系数一致性 | Python 整数参考模型生成期望值；RTL 仿真逐地址比较全部系数并定位错误 |
| 多项式乘法 | 在 `Z_q[x]/(x^N+1)` 上，通过两次正变换、RTL 逐点模乘、一次逆变换验证 |
| ROM 与 TFG 对比 | 同一运算核心分别选择唯一幂表 ROM 和在线递推；记录仿真周期与明确口径的因子存储量 |
| 存储降低 99.94%、周期增加 5.75% | 原截图数值，未经本工程确认；以本地生成的报告为准，不预填或反推为实测结果 |

## 默认配置

- 变换长度：8192（`LOG_N=13`）。
- 系数模数：2013265921；系数接口宽度：32 位。
- 原根参数：31；根的阶与逆元由 Python 验证。
- 软件环境：Ubuntu 22.04 / Python 3；RTL 仿真：Icarus Verilog。
- WSL 工程位置：`/home/xylon/projects/ckks-ntt-fpga`。

该模数和位宽便于独立、快速地验证算术与控制逻辑。它们不是一套完整的 CKKS 安全参数。迁移至多组 50–60 位 RNS 素数时，需要重新评估乘法器、存储和时序，并重新执行验证。

## 已实现范围之外

本工程提供可综合的 NTT/INTT 算术和控制基线；不包含 CKKS 编码器、密钥生成、加解密、重线性化、重缩放或安全参数选择。测试通过说明被测配置中的功能一致性，不说明完整 CKKS 系统的安全性。

在指定 FPGA 器件上完成综合、布局布线和板级测试之前，不能报告真实最高频率、吞吐率、功耗或 LUT/FF/DSP/BRAM 占用。`fpga/synth.tcl` 提供后续综合入口；其中 10 ns 时钟只是评估约束，不能当作已达成的工作频率。

## 如何使用本项目结果

引用验证结果时，应同时记录提交版本、工具版本、`N/q/W`、随机种子、ROM/TFG 模式以及对应报告。对于性能，应区分核内部周期数、包含加载和读取的总延迟、软件墙钟时间与 FPGA 实际时间。只有采用同一测试定义的数据才适合直接比较。
